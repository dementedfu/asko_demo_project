# Проверка демонстрации

Дата: 11 ноября 2026. Linux, Node 24, Chromium `/usr/bin/chromium`.

Команды: `npm test` (22 проверки), `npm run build` (TypeScript + Vite + PWA), `npm run test:e2e` (5 браузерных сценариев). Результаты относятся к локальному production build; статус размещения проверяется отдельно через Sites.

## Свидетельства

- D: `src/domain/orders.test.ts` — 9 проверок доменных правил: суммы в копейках, версии, независимые решения, идемпотентность, приёмка/согласие, исключение и возврат, пауза/QC/оплата, роли, заметки и валидация.
- R: `src/data/db.test.ts` — 9 проверок IndexedDB: сохранение, атомарность, лимиты стадий, замена фото, конфликты вкладок, отказ записи, повтор и сброс.
- U: `src/App.test.tsx`, `src/features/wizard/ShoeMap.test.tsx` — 4 проверки интерфейса, включая отказ сохранения при выходе.
- E1: `two pairs…` в `e2e/demo.spec.ts` — создание двух пар через интерфейс, карта, передача, оценки, разные решения, исключение, приватная заметка, приёмка, пересмотр, повторное согласие, пауза, неудачный/успешный QC, отказ/успех оплаты, возврат, сообщения/прочтение после перезагрузки, отзыв и повторная заявка.
- E2: `mobile photo…` — 390×844 / 360×800, реальный JPEG, предпросмотр, перезагрузка, замена, неподдерживаемый файл, удаление, отсутствие горизонтальной прокрутки.
- E3: `queue search…` — поиск, возврат исключённой принятой пары, неизменность опубликованной цены после редактирования прайса, отмена/подтверждение сброса.
- E4: `installed resources…` — Service Worker, отключение сети, перезагрузка и сохранение локального черновика без сети.
- E5: `five-pair…` — пять пар и сорок фото через интерфейс; восстановление, лимит пар, открытие пяти карточек после отключения сети, мобильная ширина 360 и desktop 1440. На контрольном прогоне роль + открытие заказа: 266 мс; это измерение этой машины, не обещание скорости всех устройств.
- I: проверка исходного кода и просмотр скриншотов; это не отдельный автоматизированный тест.

## Итоговое ревью

Один независимый проверяющий нашёл два существенных дефекта: устаревшая вкладка могла стереть новые пары/фото; выход из формы скрывал ошибку сохранения. Исправлены проверкой draftRevision, последовательной записью и ожиданием сохранения перед выходом/сменой роли/переходом по ссылкам. Регрессии включены в R/U. Перезагрузка с ещё не сохранённым вводом вызывает стандартное предупреждение браузера.

## Границы проверки

Это браузерная PWA, не отдельная iOS/Android-сборка. Установка на реальных iPhone/Android и полный аудит WCAG AA не выполнялись. Основные формы имеют явные подписи, фокус и текстовые ошибки, карта доступна через список. Наличие Service Worker и офлайн-путь проверены Chromium. Обновление браузера, очистка хранилища и режимы приватности могут удалить локальные записи. Между устройствами синхронизации нет.
