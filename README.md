# «Другая пара» — демонстрационное приложение чистки обуви

Проект собственного сервиса чистки и ухода за обувью: клиент описывает состояние нескольких пар, мастер оценивает работы, стороны согласуют стоимость, затем обувь проходит приёмку, выполнение и возврат.

## Текущее состояние

**Этап продуктового проектирования.** Концепция, спецификация и дизайн подготовлены для согласования. Полное приложение ещё не реализовано: в этом коммите нет команды запуска продукта и нет утверждения о прохождении его тестов.

Временное название — предложение для обсуждения. 11 ноября 2026 пользователь выбрал визуальное направление A. В итоговом приложении прежний шрифт макетов заменяется на Golos Text; тёплая палитра сохраняется. Сами макеты не являются действующим сервисом.

## Предлагаемая первая версия

Адаптивная PWA с клиентским интерфейсом и кабинетом мастера. React, TypeScript и Vite; локальная база IndexedDB для общих данных демонстрационных ролей и настоящих изображений.

Основной цикл: несколько пар → карта проблем и фото → вопросы мастера → отдельные версии оценки → согласие/отказ → приёмка и возможный пересмотр → работа и контроль качества → демонстрационная оплата → частичный или полный возврат → обратная связь и повторная заявка.

## Границы демо

- Только синтетические исходные клиентские данные и демонстрационные цены.
- Общая база ролей находится в одном профиле браузера; между устройствами не синхронизируется.
- Смена роли не является рабочей авторизацией или серверной защитой.
- Платежи, SMS и курьерские действия эмулируются и обозначаются соответствующим образом.
- Пользовательские фотографии остаются в браузере; в публичный репозиторий не загружаются.
