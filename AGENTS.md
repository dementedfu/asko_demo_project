# Работа с проектом

Проект — демонстрация личной мастерской чистки обуви, на синтетических данных.

- Используйте доступные навыки Superpowers для задачи. Пользователь предпочитает короткие рабочие циклы и минимум накладных расходов. Не создавайте отдельные сайты для выбора оформления без запроса.
- Сначала проверяйте согласованную спецификацию `specs/001-shoe-care-demo/spec.md`. Spec Kit установлен в `.specify`, команды Codex — `.agents/skills/speckit-*`.
- Визуальное направление A: молочный фон, оливковые акценты, Golos Text. Сохраняйте мобильный сценарий и кабинет мастера.
- Бизнес-переходы находятся в `src/domain/orders.ts`, транзакции — в `src/data/db.ts`. Компоненты не должны обходить эти правила.
- Оценка и согласие привязаны к конкретной паре и версии. Перед стартом нужны приёмка, состояние и актуальное согласие. Исключённую принятую пару нужно вернуть.
- Данные и изображения остаются в IndexedDB. Не добавляйте реальные оплаты, сообщения или отправку пользовательских фото без нового запроса.
- До завершения существенных изменений выполняйте `npm test`, `npm run build`, соответствующие браузерные проверки. Обновляйте `docs/VALIDATION.md` по фактическим результатам.
- Не загружайте `node_modules`, `dist`, личный контекст, токены и пользовательские изображения в GitHub. Публикуйте только явно разрешённый объём.
